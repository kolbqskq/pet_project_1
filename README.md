Я разрабатываю игру "Шахтёры" (учебный проект).
Цель игры: купить все необходимые инструменты для продуктивной работы предприятия за наименьшее время.
Для увеличения добычи угля вам нужно нанимать шахтёров различного класса.
Изначально у вас уже имеется пассивный доход в размере 1 угля в секунду.
Чтобы закончить игру, вам нужно приобрести все инструменты.

Взаимодействие с игрой осуществляется по протоколу HTTP:

POST /miners + JSON: "class" — нанять шахтёра

GET /miners/prices — получить информацию о каждом классе шахтёров

POST /equipment + JSON: "equipment" — купить инструмент

GET /equipment/prices — получить информацию о каждом инструменте

GET /equipment — получить информацию о состоянии инструментов

GET /stats — получить информацию о всех нанятых шахтёрах

GET /stats?by=... — получить информацию о нанятых шахтёрах определённого класса

POST /game/save?name=... — сохранить игру

POST /game/load?name=... — загрузить игру

GET /game/list — список сохранений

GET /enterprise/balance — узнать баланс угля

POST /enterprise/end — закончить игру
